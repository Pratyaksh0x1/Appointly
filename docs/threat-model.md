# Appointly Threat Model (STRIDE-Lite)

## 1. Scope & System Overview

Appointly is an autonomous voice agent designed for Indian healthcare clinics (Gnani AI Hackathon), integrating:

- **Speech & AI Pipeline:** Gnani Timbre (TTS), Prisma (STT), Evon 30B LLM (or mock equivalents).
- **Core Database & State:** Neon Serverless PostgreSQL with transactional outbox and strict serializable constraints.
- **Frontend Interfaces:** Browser-based Realtime Voice WebSocket client (`/voice-test.html`) and Doctor Dashboard (`/index.html`) using Server-Sent Events (SSE).

Every tool parameter is validated server-side by strict **Zod schemas** before SQL execution.                                                                | LLM phrasing could be nudged to speak inappropriate or off-topic words. _Future hardening: dual-LLM guardrail filter on outgoing responses._                                          |
| **Tampering**              | **JSON Body Prototype Pollution / Null Byte Injection:** Malicious payloads with `__proto__`, `constructor`, or null bytes sent to REST endpoints.      | **Medium**   | `sanitizeObject` and `sanitizeString` recursively strip null bytes, ASCII control characters, and object prototype properties before JSON parsing.                                                                                                                                                                                 | Zero known residual risk for JSON routes.                                                                                                                                             |
| **Repudiation**            | **Denial of Action:** Patient or clinic claims an appointment was cancelled or booked without authorization.                                            | **Medium**   | Immutable audit trail in Neon PostgreSQL `outbox` table and Pino structured JSON logging with immutable `callId`, `request_id`, and timestamps.                                                                                                                                                                                    | Log retention purging after `TRANSCRIPT_RETENTION_DAYS` (30 days) removes older call logs for DPDP compliance.                                                                        |
| **Information Disclosure** | **PHI / Medical Data Leakage:** Caller asks assistant for another patient's condition, diagnosis, or prescription.                                      | **Critical** | **Strict Zero Medical Diagnosis Rule.** Appointly is architected exclusively for triage and scheduling; the prompt and state machine explicitly forbid medical diagnostic claims. No medical records are stored or exposed to voice callers.                                                                                       | Ambient room noise picked up by caller's mic could contain background talk. _Future hardening: client-side noise suppression._                                                        |
| **Information Disclosure** | **Secrets & PII in Application Logs:** API keys, database credentials, phone numbers, or Aadhaar numbers leaking to stdout.                             | **High**     | Automated recursive log redactor: `maskPhone`, `maskEmail`, `redactPiiFromTranscript`, and key redaction list (`token`, `secret`, `password`, `key`, `apiKey`, etc.).                                                                                                                                                              | Zero plain PII or secrets logged; verified by automated CI unit test suite.                                                                                                           |
| **Information Disclosure** | **Raw Audio Storage Risk:** Patient voice recordings stored on unencrypted server disks.                                                                | **High**     | **Zero Raw Audio Storage Policy:** `STORE_RAW_AUDIO=false`. Voice audio chunks are processed purely ephemerally in RAM (Buffer) for VAD and STT streaming, then immediately garbage collected. Zero `.wav`, `.raw`, or `.pcm` files touch disk.                                                                                    | Ephemeral RAM dumps during core dump on process crash could contain transient audio buffers.                                                                                          |
| **Denial of Service**      | **AI Credit Exhaustion / Denial of Wallet:** Malicious attacker flooding voice calls to exhaust the 5,000 API credit budget.                            | **Critical** | **CostMeter Defense:** Enforces strict per-call limits (50 credits), daily budget caps (2,000 credits), and global cap (5,000 credits). Fail-fast error `CreditLimitExceededError` terminates turns before external AI invocations. Sliding-window rate limiter limits IPs/sessions to 120 req/min.                                | Rapid IP rotation via botnets could consume credits up to daily limit before triggering IP bans. _Future hardening: Cloudflare Turnstile / CAPTCHA on initial web session handshake._ |
| **Denial of Service**      | **Payload Flooding / Slowloris:** Attacker streams multi-gigabyte HTTP payloads or opens endless idle WebSocket connections.                            | **Medium**   | `MAX_REQUEST_SIZE_BYTES` (1MB limit) returns HTTP 413 and immediately destroys streams. WebSocket server enforces 45-second idle timeout and 5-minute maximum call duration.                                                                                                                                                       | None; resource exhaustion is bounded by strict timeouts.                                                                                                                              |
| **Elevation of Privilege** | **Database Superuser Compromise:** Application runtime executing DDL commands (`DROP TABLE`, `ALTER USER`).                                             | **High**     | Dual-role database architecture: `appointly_app` application role granted strictly `SELECT`, `INSERT`, `UPDATE`, `DELETE` on operational tables; DDL (`DROP`, `ALTER`, `CREATE`) restricted strictly to the migration role (`appointly_admin`). Documented in `docs/db-roles.md` and `scripts/setup-least-privilege-db-roles.sql`. | If administrator connection string is inadvertently supplied in production `.env`, app inherits superuser permissions.                                                                |

## 3. Residual Risks & Honest Assessment

1. **Voice Biometric Verification Absence:**
   - Appointly currently authenticates callers via Name + Last 4 Digits of Phone Number. While adequate for routine clinic triage, high-security clinical actions (such as accessing lab results or prescribing medications) require cryptographic OTP or clinical portal login.
2. **LLM Hallucination Boundaries:**
   - While deterministic code guardrails strictly prevent invalid dates, slots, fees, or unauthorized DB commits, the natural phrasing of the LLM in Hinglish could occasionally vary. This is mitigated by explicit state machine transitions and confirmation readbacks.
3. **Telemetry & Upstream Telephony Resilience:**
   - In production telephony deployments (SIP/PSTN trunking), carrier network jitter may cause transient packet loss. Appointly's pre-cached audio phrase fallback and automatic callback persistence guarantee that callers are never left stranded.
